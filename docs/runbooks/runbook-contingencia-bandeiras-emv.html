Contingência de Comunicação com Bandeiras (Visa / Mastercard / Elo)

Procedimento para chaveamento de link ExpressRoute / Direct Connect secundário quando a taxa de Response Code 91 (Issuer or Switch Inoperative) ultrapassa 3%.

Comandos de Chaveamento de Rota

# Verificar status dos túneis das bandeiras
kubectl exec -it deploy/brand-connector-router -n autorizacao-prd -- ./cli status --all-brands

# Drenar link primário degradado e forçar tráfego pela rota de contingência
kubectl set env deploy/brand-connector-router -n autorizacao-prd PRIMARY_LINK_DRAINED=true
