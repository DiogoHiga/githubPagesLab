Runbook: Latência Alta no Autorizador TEF / POS

Documento simples criado para validar a indexação automática via GitHub Actions sem alterar manualmente o arquivo docs.json.

1. Verificar Saúde dos Pods do Gateway TEF

Checar latência e status das réplicas no namespace produtivo de captura física:

kubectl get pods -n captura-fisica-prd -l app=tef-authorizer-gateway
kubectl top pods -n captura-fisica-prd -l app=tef-authorizer-gateway

2. Validar Fila de Mensageria ISO-8583

Confirmar se há retenção de pacotes transacionais entre o concentrador POS e as bandeiras:

kubectl logs deploy/tef-authorizer-gateway -n captura-fisica-prd --tail=100 | grep -i "timeout"
